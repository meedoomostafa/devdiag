# Changelog

Notable changes to DevDiag. From v0.5.0 onward, detailed per-release notes
are generated by the release pipeline and published on the
[GitHub Releases](https://github.com/meedoomostafa/devdiag/releases) page;
this file tracks the highlights.

## Unreleased

### Breaking
- `baseline create` now requires explicit selection: `--finding <id>`
  (repeatable, fail-closed on unknown IDs) or `--all` for a deliberate full
  sweep. Bare `baseline create --reason ...` exits 2.

### Added
- Release pipeline: linux amd64/arm64 binaries, `checksums.txt`, SPDX SBOMs,
  and signed SLSA build provenance on every release; `v0` major tag for
  action consumers, moved only after a release fully publishes.
- `install.sh` installs verified release binaries (mandatory checksum,
  fail-closed) and only falls back to source builds for branches/SHAs.

### Changed
- `F-DOCKER-001` severity is context-tiered: `high` when the repo
  demonstrably runs containers (Compose/devcontainer) or on explicit
  `check containers`; `medium` for Dockerfile-only repos.
- The GitHub Action stamps real versions into reports (action-ref fallback
  for tarball-extracted action paths); runner reports no longer say `dev`.
- `latest` is now a release-pipeline-owned alias moved atomically with
  `v0`, only after a release fully publishes; pin `@v0`, `@latest`, or a
  full commit SHA (SHA recommended for security-sensitive use).

## v0.4.0 — 2026-07-26

Full-system hardening release (systematic review, phases 1–3).

- **Redaction**: CI collector env values (GitHub/GitLab) and compose
  interpolation defaults can no longer leak bare secrets at default
  redaction; new `evidence_secret_sources` and `interpolation_defaults`
  rules; source-to-sink canary e2e suite.
- **Exit codes**: usage errors exit 2 (not 8); `fix --apply` permission
  failures exit 4; `scan --save-report` persist failures are errors;
  black-box contract table pins the whole matrix.
- **Action**: exact run-id report attribution (no stale/foreign report
  reuse); SHA-pinned action dependencies; PR-gating redaction-canary and
  error-propagation CI jobs.
- **CI**: gofmt, staticcheck, full-suite race detector, shellcheck,
  actionlint gates.

## v0.3.x and earlier — 2026-06

Initial public milestones: scan/check/fix/baseline/capsule/inspect command
surface, deterministic rule engines, redaction engine, remote sync (SSH,
container, k8s), trace backends, rule packs, GitHub Action, TUI, and the
live signoff harness.
